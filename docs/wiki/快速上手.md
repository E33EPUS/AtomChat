**装上它，并且第一次把面板用起来。** 全程大约三分钟。

## 1. 选对 JAR

去 [Releases](https://github.com/E33EPUS/AtomChat/releases) 下载与你平台对应的那一个：

| 你的游戏 | 下载这个文件 | 还需要 |
|---|---|---|
| Minecraft 1.21.1 + Fabric | `atomchat-Fabric-1.21.1-x.y.z.jar` | Fabric Loader 0.16.0+ 与 Fabric API，Java 21+ |
| Minecraft 1.21.1 + NeoForge | `atomchat-NeoForge-1.21.1-x.y.z.jar` | NeoForge 21.1+，Java 21+ |
| Minecraft 1.20.1 + Forge | `atomchat-Forge-1.20.1-x.y.z.jar` | Forge 47+，Java 17 |

> ⚠️ 三个平台**不能混用**：装错加载器的 JAR 不会加载。也请注意 Forge 版里还有一个带 `-slim` 后缀的文件，它是给开发用的、不带内嵌依赖，正常玩请用不带 `-slim` 的那个。

## 2. 放进 mods

把 JAR 拖进 `.minecraft/mods/`（整合包实例就是该实例自己的 `mods/` 目录）。

想让**服务器**托管图片、同步头像，或者给玩家下发表情包与常用语，就把同一个 JAR 也放进服务端的 `mods/`。这一步是可选的 —— 不装也能正常用，只是图片会走第三方图床。服务端侧的细节见 [服主手册](服主手册)。

## 3. 打开面板

启动游戏进入世界后：

- 按**聊天键**（默认 `T` 或 `/`）—— AtomChat 会接管原版聊天界面，直接进入公屏输入状态；
- 或按 **`Y`**（默认按键，可在 `选项 → 控制 → 按键绑定 → AtomChat` 里改）—— 直接打开面板并恢复上次所在的页面。

面板长这样：顶部是「公屏」和系统时间，中间是消息列表，底部是输入栏，最下面是三个标签页 —— **聊天 / 个人 / 设置**。

## 4. 先试这五件事

1. **发一条消息**：打字，回车。文字超过一行时输入框会自动长高，上下箭头仍可在行间移动光标。
2. **发一张图**：点输入栏左边的图片按钮选图；或者直接把图片文件拖进游戏窗口；或者复制图片后按 `Ctrl+V`。三种方式都会先上传、再把图片代码插入草稿，确认无误后回车发送。
3. **用表情**：点表情按钮，面板上有 `表情` / `颜文字` / `表情包` 三个标签页。点一下即插入（表情包会自动上传并插入草稿，然后关闭面板）。
4. **右键一条消息**：可以复制，或引用回复（引用会带上原消息的气泡）。图片消息还多一个「保存」，能把原图存到本地。
5. **点头像**：单击打开玩家档案页；300 毫秒内再点一次是 QQ 式的「戳一戳」；右键头像呼出菜单 —— @ 提及、私聊、传送、屏蔽。

## 5. 换成你自己的样子

点底部 **设置** 标签，是一个 Win11 风格的 2×2 磁贴主页：**外观 / 聊天 / 隐私与屏蔽 / 关于**。

所有选项**即时生效并立刻写盘，不需要重启游戏**。想先玩两个的话：

- `外观 → 界面缩放` 从 x0.75 到 x1.50，能整套缩放 UI（小屏笔记本很有用）；
- `外观 → 自定义壁纸` 换成自己的图，长边会自动降到 1024 像素。

更多外观项、以及完整的配置项清单，见 [外观与配置](外观与配置)。
