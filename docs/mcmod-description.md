原子聊天（AtomChat）是基于 E33聊天界面（E33Chat） 理念而开发的全新聊天美化mod，旨在把原版聊天屏改造成「手机 App」风格的独立聊天面板，元素包括：圆角气泡、自定义头像、真实玩家名、表情 / 颜文字 / 表情包、图片与 GIF 动图消息、服务端媒体托管、复制引用、多行输入与 QQ 式动效，以及除聊天界面外的更多界面。精神续作（bushi）

渲染层使用 Skija。所有界面由矢量绘制，不依赖原版聊天纹理。

[h1=原版优化]

💬 聊天气泡与头像 — 你的消息显示在右侧，其他人的在左侧，附带真实玩家名称和圆形皮肤头像；

🧹 简洁原版 HUD 占位符 — 在面板外部，图片代码显示为绿色 `[图片]`，引用显示为蓝色 `[引用]`；

📝 多行输入 — 输入框最多显示两行，内容更长时内部滚动；按上/下箭头可在行间移动，而单行草稿则保留原版聊天历史记录；

🧠 消息捕获 — 真实玩家身份从 MessageHandler 的三个通道中捕获（支持花名服）；未知消息会降级为系统文本，而不是被猜错；

📑 保留聊天记录 — 开启后按服务器 / 世界保存在磁盘，重进同一服务器恢复，可设置自动清理；

🔃 公屏消息分类过滤 — 标题栏返回键旁的按钮在「全部 / 仅系统 / 仅玩家」间循环，图标随状态切换；纯视图过滤，未读角标与会话预览仍统计全部消息；

✏️ 文字选取与防刷屏 — 可跨多条消息拖选后 Ctrl+C 一次复制；连续相同的消息合并并显示次数，同一发送者的连续消息紧凑排列。

[h1=特点]

🖼️ 图片消息 — 原生渲染 `[[CICode]]`，并与 E33Chat / ChatImage 系列模组互通；图片保持宽高比，GIF 动图在气泡内自动循环播放，透明底 PNG / GIF 直接透出面板背景，支持右键保存原图；

📤 发送本地图片 — 可通过图片按钮选取、拖拽到窗口内，或使用 Ctrl+V 粘贴；选取器以“详细信息”视图打开，并显示内联缩略图；

😊 表情 / 颜文字 / 表情包 — 三个标签页带滑动指示器与全宽推入切换动画；表情包存储在本地（png / jpg / jpeg / gif，最多 10 个），gif 在面板里显示首帧、发送出去后正常播放；

🔔 通知横幅与音效 — 被 @、被引用、收到私聊时面板顶部弹出横幅（点击跳转原消息并高亮），配套原创合成的提示音，可分别开关并调音量；

🔗 富文本消息 — 支持颜色、下划线、点击和悬停提示：/tell、坐标、FTB 接受/拒绝以及外部链接均可点击；纯 URL 自动转为链接；

📋 复制 / 引用回复 / 保存 — 右键气泡呼出菜单，可复制或引用回复；图片气泡额外提供“保存”选项；

🧭 @ / 屏蔽 / 个人档案 / tp / 私聊 — 右键头像呼出菜单，可 @、屏蔽、跳转个人档案、跳转私聊界面和快速 tp；单击头像打开档案页，双击触发 QQ 式戳一戳；

🪢 私聊 — 聊天列表列出当前在线玩家，按「公屏 → 在线玩家 → 最近离线」排序，带未读红点与分会话草稿，离线 / 屏蔽对象只读；

🖥️ 个人档案页 — 从聊天或会话列表推入玩家档案：数据总览、复制按钮、角色标识；

⚡ 常用语 — 输入栏闪电按钮打开常用语列表，点选插入输入框（不直接发送）；

🎨 Skia 矢量界面与动效 — 圆角气泡、模糊背景、滚动和 QQ 风格的滑入动画均为矢量绘制；

📱 自定义壁纸 / 头像 — 上传本地图片，裁剪后替换界面背景 / 玩家头像；

🎛️ 主题与配色 — 一键切换主题预设，设置页可逐项调整全部界面配色，每项带实时预览；

🌍 本地化 — 支持简体中文和英文；切换 Minecraft 游戏语言即可应用；

😍 高度自定义 — 外观 / 颜色 / 偏好 等等均可配置。

[h1=服务端媒体托管]

服务端也安装 AtomChat 后，聊天图片与 GIF 可以托管在服务器上，不再依赖第三方图床：

图片上传到服务端后由服务端分发给其他玩家，按内容（sha256）寻址，相同的图只存一份；

接收方按需分块拉取，全程走游戏连接，不开 HTTP 端口、不对外暴露；

服务端具备单文件大小上限、图片魔数校验、按玩家上传限速，并按总容量与时效自动修剪；

服务端未安装 / 关闭托管 / 文件超限 / 上传失败时，自动回退第三方图床，行为与旧版一致；

同一个 hostingEnabled 总开关也管自定义头像同步。

服务端配置位于 <服务端游戏目录>/config/atomchat/atomchat-server.json，可调项：

hostingEnabled（默认 true）— 总开关：是否托管聊天图片 / GIF 与玩家头像；

maxFileKb（默认 2048）— 单个托管文件的大小上限（KB），超出则回退图床；

maxTotalMb（默认 512）— 媒体库总容量上限（MB），超出后按最旧优先删除；

retentionDays（默认 30）— 托管文件保留天数，0 表示永久保留；

uploadCooldownMs（默认 3000）— 同一玩家两次上传之间的最小间隔（毫秒）。

[h1=配置与存储]

路径 — .minecraft/config/atomchat/ 下存放 atomchat-client.json / avatar / debug / emotes / history / wallpaper 文件；

[推荐] 游戏内设置页（磁贴主页：外观 / 聊天 / 隐私与屏蔽 / 关于）— 所有选项即时生效并立即写盘，无需重启。颜色项带预设色板、`+` 号自定义拾色器与实时预览；

配置文件 — 直接编辑 atomchat-client.json（首次启动自动生成，手动修改后需重启游戏）；

聊天记录 — 开启后写入 /history 下，各存档 / 服务器独立；

自定义壁纸 — 存放在 /wallpaper 下；

自定义头像 — 存放在 /avatar 下；

表情包 — 存放在 /emotes 下（png / jpg / jpeg / gif，最多 10 个）；

服务端配置 — 服务端也装 AtomChat 时位于 <服务端游戏目录>/config/atomchat/atomchat-server.json，托管下来的媒体存放在 <服务端游戏目录>/atomchat-data/media/ 下；

客户端媒体缓存 — 自动下载的聊天图片与他人头像数据位于 <游戏目录>/atomchat-data/ 下（上限 500 文件 / 100 MB，可在 设置 → 关于 中查看并清空）。

[h1=已知限制]

目前支持 Fabric / NeoForge 1.21.1 与 Forge 1.20.1；Skija Windows x64 原生库已内置，Linux / macOS 尚未打包（无法运行）；

服务端媒体托管需要服务端也安装 AtomChat；未安装或关闭托管时图片仍走第三方图床 uguu.se（约 3 小时过期）。超过 maxFileKb（默认 2 MB）的文件不会再上传服务端，而是直接回退图床，客户端也不会为它重新压缩；

托管的端到端联调目前只做过「单人 / 局域网主机的服务端侧」一种场景，独立服务器（尤其 Linux）与两个客户端互相拉图尚未实测；

暂无 E33Chat 的私聊侧边栏、搜索等能力；

玩家身份解析为尽力而为：tell-click 结构捕获、离线 seen 缓存、ownDisplayName 多级降级；极端未知格式回退灰字。

[h1=隐私与数据]

你发送的本地图片会被上传到第三方图床（默认 uguu.se），或（服务端开启托管时）保存到你所在服务器的磁盘上，且他人可保存 / 转发，请勿发送敏感或私密内容；

服务端托管只通过游戏连接传输字节，不开放 HTTP 端口，也不会把媒体暴露给未连接的玩家；

开启托管的服务端会在 <服务端游戏目录>/atomchat-data/media/ 保留一份你的图片副本，由服务端按 maxTotalMb / retentionDays 修剪，管理员也可随时手动删除；

你的消息可被开启聊天记录的用户保存，请勿发送敏感或私密内容；

模组不上传任何遥测 / 个人信息；

图片上传仅在主动选择 / 粘贴 / 拖入图片时发生；

本地配置与表情包仅存于 .minecraft/config/atomchat/，不会自动同步。

[h1=常见问题]

需要装服务端吗？— 不需要，AtomChat 是纯客户端模组。服务端（或单人 / 局域网主机的服务端侧）装了 AtomChat 后，会额外激活服务端媒体托管与自定义头像同步；

图片是走图床还是走服务器？— 服务端装了 AtomChat 且 hostingEnabled=true 时优先走服务器，消息里是 atomchat-media:<id> 短链；服务端没装 / 关闭托管 / 文件超过 maxFileKb / 上传失败时自动回退 uguu.se 图床。日志里托管成功是 Stored hosted media，回退图床是 Uploaded chat image to the external host；

图床链接会过期吗？— uguu.se 链接约 3 小时过期；服务端托管的内容不过期，由服务端按容量与时效自动清理；

怎么发图片？— 点图片按钮选择本地图片，或拖图片进窗口 / Ctrl+V 粘贴；上传完成后自动插入草稿，再回车发送；

为什么某条消息显示为灰色系统消息？— 客户端无法确定它是玩家消息时会保守归为系统灰字（例如昵称插件使用无法解析的格式）；

表情包存在哪里？— .minecraft/config/atomchat/emotes/，最多 10 个，支持 png / jpg / jpeg / gif；

怎么改颜色 / 大小？— 游戏内 设置 → 外观 即时调整（颜色项带预设与自定义拾色器）；也可以编辑 config/atomchat/atomchat-client.json 后重启游戏；

可以放进整合包吗？— 可以。若整合包分发 JAR，请保留第三方声明。
